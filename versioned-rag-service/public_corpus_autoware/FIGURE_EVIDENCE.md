# 图片证据边界

当前中文 Autoware 语料没有经过人工核验的图片 OCR 证据。`figure_evidence.json` 与 `figure_evidence_reviewed.json` 均为空；服务不把图片 alt 文本或页面截图描述冒充为图内文字。

HTML 正文转换可能保留原文的图片说明或链接，但这不等于识别了图片像素。询问流程图、参数截图或界面截图里的信息时，当前系统可能只能返回页面文字，不能据此声称覆盖了图片内容。

后续若增加图片检索，应在固定的中文版本快照中建立图片级来源、哈希和页内位置，先用真实业务图片问题构造评测集，再人工核验 OCR/视觉提取结果及引用位置。完成独立评测前，不把派生图像文字接入默认检索链路。
