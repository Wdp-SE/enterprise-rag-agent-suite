# /api/system/diagnostics/struct

## 状态

- 最后版本: v1.3.0
- 方法: notification
- 数据类型: [autoware_adapi_v1_msgs/msg/DiagGraphStruct](../../../../../types/autoware_adapi_v1_msgs/msg/DiagGraphStruct/)

## 描述

这是诊断的静态部分. 如果使用新 ID 发布静态数据,请忽略使用旧 ID 的动态数据. 请参阅 [诊断](../../../../../features/diagnostics/) 了解详细信息.

## 消息

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| stamp | builtin_interfaces/msg/Time | 发送此消息时的时间戳. |
| id | string | ID 来检查 struct 和 status 之间的对应关系. |
| nodes | autoware_adapi_v1_msgs/msg/DiagNodeStruct[] | 诊断图中节点的静态数据. |
| links | autoware_adapi_v1_msgs/msg/DiagLinkStruct[] | 诊断图中链接的静态数据. |
