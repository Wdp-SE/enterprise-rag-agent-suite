# 如何将您的车辆集成到 AWSIM 环境中

## 概述

[AWSIM](https://github.com/tier4/AWSIM) 是 TIER IV 为 训练和评估自动驾驶系统. 它为模拟各种真实场景提供了一个逼真的虚拟环境,使 用户在实际车辆上部署之前测试和改进他们的自动驾驶系统.

## 设置 Unity 项目

要将您的环境和车辆添加到 AWSIM 模拟, 您需要在计算机上设置 [Unity](https://unity.com/) 环境. 请按照 [`设置 Unity 项目`](https://tier4.github.io/AWSIM/GettingStarted/SetupUnityProject/) 中的步骤作 文档页面 在计算机上设置 Unity 环境.

## 新车集成

要将您的车辆整合到 AWSIM 环境中, 您需要车辆的 3D 模型文件 (.dae, .fbx). 请参考 [`添加新车辆] 的步骤 documentation page`](https://tier4.github.io/AWSIM/Components/Vehicle/AddNewVehicle/AddAVehicle/) 将您自己的车辆添加到 AWSIM 项目环境.在这些步骤中,您将配置 您的传感器 URDF 设计在您的车辆上. 我们的教程工具显示在下图中的 AWSIM 环境中.

## 环境集成

为 AWSIM 创建自定义 3D 环境是可行的, 但建议遵循 .fbx 文件格式. 材质和纹理应存储在单独的目录中 与 Unity 无缝集成.这种格式有助于材料 导入和导入过程中的替换. 请参考 [`添加环境文档页面`](https://tier4.github.io/AWSIM/Components/Environment/AddNewEnvironment/AddEnvironment/) 将您的自定义环境添加到 AWSIM 项目环境.
