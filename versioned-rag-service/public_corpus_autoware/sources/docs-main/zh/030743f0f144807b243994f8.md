# 传感器组件设计

## 概述

传感器组件是一组模块,这些模块对原始传感器数据进行一些原始预处理.

传感器输入格式在此组件中定义.

## 角色

- 数据格式的抽象化,以便使用来自不同供应商的传感器
- 执行每个组件所需的公共/原始传感器数据处理

## 输入

### 输入类型

| 传感器数据 | 消息类型 |
| --- | --- |
| 点云(LiDAR、深度相机等) | sensor_msgs/msg/PointCloud2.msg |
| 图像(RGB、单色、深度等相机) | sensor_msgs/msg/Image.msg |
| 雷达扫描 | radar_msgs/msg/RadarScan.msg |
| 雷达轨迹 | radar_msgs/msg/RadarTracks.msg |
| GNSS -INS 位置 | sensor_msgs/msg/NavSatFix.msg |
| GNSS -INS 方向 | autoware_sensing_msgs/GnssInsOrientationStamped.msg |
| GNSS -INS 速度 | geometry_msgs/msg/TwistWithCovarianceStamped.msg |
| GNSS -INS 加速 | geometry_msgs/msg/AccelWithCovarianceStamped.msg |
| IMU | sensor_msgs/msg/Imu.msg |
| 超声波 | sensor_msgs/msg/Range.msg |
