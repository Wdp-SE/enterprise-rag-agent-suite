# 车辆监控

AD API 提供当前车辆状态,用于远程监控、乘客可视化等. 根据要监控的数据,使用以下 API.

## 车辆状态

[车辆状态](../../features/vehicle-status/) 提供基本信息,例如运动学、指示器和尺寸. 这使远程作员能够了解车辆的位置和速度. 对于 FMS 等应用,它可以帮助找到需要帮助的车辆,例如卡住或突然制动的车辆. 还可以从车辆尺寸确定到物体的实际距离.

## 规划因素

[规划因素](../../features/planning-factors/) 提供车辆的规划状态. HMI 可以使用它来警告车辆的突然移动,并与乘客分享停止原因,以实现舒适的驾驶.

## 检测到的物体

[感知](../../features/perception/) 提供 Autoware 检测到的对象. HMI 可以使用它来可视化车辆周围的物体.
