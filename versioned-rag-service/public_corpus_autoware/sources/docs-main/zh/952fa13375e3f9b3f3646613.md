## 输入

| Name | Topic | Type | Description |
| --- | --- | --- | --- |
| 超声 | T.B.D | sensor_msgs/Range | Distance data from ultrasonic radar driver. |
| 相机图像 | T.B.D | sensor_msgs/Image | Image data from camera driver. |
| 雷达轨迹 | T.B.D | radar_msgs/RadarTracks | Tracks from radar driver. |
| 雷达扫描 | T.B.D | radar_msgs/RadarScan | Scan from radar driver. |
| 激光雷达点云 | /sensing/lidar/<lidar name>/pointcloud_raw | sensor_msgs/PointCloud2 | Pointcloud from lidar driver. |
| GNSS -INS 位置 | T.B.D | geometry_msgs/NavSatFix | Initial pose from GNSS driver. |
| GNSS -INS 取向 | T.B.D | autoware_sensing_msgs/GnssInsOrientationStamped | Initial orientation from GNSS driver. |
| GNSS 速度 | T.B.D | geometry_msgs/TwistWithCovarianceStamped | Initial velocity from GNSS driver. |
| GNSS 加速度 | T.B.D | geometry_msgs/AccelWithCovarianceStamped | Initial acceleration from GNSS driver. |

## 输出

| Name | Topic | Type | Description |
| --- | --- | --- | --- |
| 超声 | T.B.D | sensor_msgs/Range | Distance data from ultrasonic radar. Used by the Perception. |
| 相机图像 | T.B.D | sensor_msgs/Image | Image data from camera. Used by the Perception. |
| 组合雷达航迹 | T.B.D | radar_msgs/RadarTracks.msg | Radar tracks from radar. Used by the Perception. |
| 雷达点云 | T.B.D | radar_msgs/RadarScan.msg | Pointcloud from radar. Used by the Perception. |
| 激光雷达点云 | /sensing/lidar/<lidar group>/pointcloud | sensor_msgs/PointCloud2 | Lidar pointcloud after preprocessing. Used by the Perception and Localization. <lidar group> is a unique name for identifying each LiDAR or the group name when multiple LiDARs are combined. Specifically, the concatenated point cloud of all LiDARs is assigned the <lidar group> name concatenated . |
| GNSS -INS 姿势 | T.B.D | geometry_msgs/PoseWithCovarianceStamped | Initial pose of the ego vehicle from GNSS . Used by the Localization. |
| GNSS -INS 方向 | T.B.D | sensor_msgs/Imu | Orientation info from GNSS . Used by the Localization. |
| GNSS 速度 | T.B.D | geometry_msgs/TwistWithCovarianceStamped | Velocity of the ego vehicle from GNSS . Used by the Localization. |
| GNSS 加速 | T.B.D | geometry_msgs/AccelWithCovarianceStamped | Acceleration of the ego vehicle from GNSS . Used by the Localization. |
