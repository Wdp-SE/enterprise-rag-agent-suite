# /api/local/command/acceleration

## 状态

- 最后版本: not released
- 方法: realtime stream
- 数据类型: [autoware_adapi_v1_msgs/msg/AccelerationCommand](../../../../../types/autoware_adapi_v1_msgs/msg/AccelerationCommand/)

## 描述

发送本地运行模式下使用的加速命令. 如需使用此 API,请按照 [手动控制](../../../../../features/manual-control/).

## 消息

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| stamp | builtin_interfaces/msg/Time | 发送此消息时的时间戳. |
| acceleration | float32 | 目标加速度 [m/s^2]. |
