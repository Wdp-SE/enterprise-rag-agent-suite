# 随机测试模拟

注意

除了构建和安装 Autoware 之外,运行 场景仿真(Scenario Simulator) 还需要一些额外的步骤,因此请确保在继续之前先完成场景仿真 [安装](../installation/).

## 运行步骤

1. 移动到已构建 Autoware 和 场景仿真(Scenario Simulator) 的工作区目录.
2. 获取工作区设置脚本： `sourceinstall/setup.bash`
3. 运行模拟： `ros2launchrandom_test_runnerrandom_test.launch.py\ architecture_type:=awf/universe/20240605\ sensor_model:=sample_sensor_kit\ vehicle_model:=sample_vehicle`

（图片说明：random_test_runner；未对图片像素执行 OCR）

有关支持的参数的更多信息,请参阅 [random_test_runner](https://github.com/tier4/scenario_simulator_v2/blob/master/docs/user_guide/random_test_runner/README.md#node-parameters) 文档.
