# 创建矢量地图

## 概述

在本节中,我们将解释如何使用 TIER IV 的 [Vector Map Builder tool](https://tools.tier4.jp/feature/vector_map_builder_ll2/) 创建 Lanelet2 地图.

还有其他替代工具,例如 基于 Unity 的应用程序 [MapToolbox](https://github.com/autocore-ai/MapToolbox) 和 基于 Java 的应用程序 [JOSM](https://josm.openstreetmap.de/) 可用于创建 Lanelet2 地图. 我们将在本教程中使用 TIER IV 的 Vector Map Builder 因为它可以在浏览器上运行,而无需安装额外的依赖应用程序.

## 矢量地图生成器

您需要 TIER IV 帐户才能使用 Vector Map Builder 工具. 如果是第一次使用该工具, [创建 TIER IV 帐户](https://docs.web.auto/en/user-manuals/tier-iv-account/quick-start) 以便使用 [Vector Map Builder 工具](https://tools.tier4.jp/feature/vector_map_builder_ll2/). 有关此工具的更多信息, 请查看 [官方指南](https://docs.web.auto/en/user-manuals/vector-map-builder/introduction).

您可以按照这些页面创建 Lanelet2 地图并了解其监管要素.
