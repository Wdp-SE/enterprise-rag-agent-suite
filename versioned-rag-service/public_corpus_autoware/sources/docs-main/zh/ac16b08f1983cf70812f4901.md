# /api/routing/route

## 状态

- 最后版本: v1.0.0
- 方法: notification
- 数据类型: [autoware_adapi_v1_msgs/msg/Route](../../../../types/autoware_adapi_v1_msgs/msg/Route/)

## 描述

以 lanelet 格式获取带有 waypoint Segments 的路线.如果未设置 route,则为空.

## 消息

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| header | std_msgs/msg/Header | 用于姿势转换的标头 |
| data | autoware_adapi_v1_msgs/msg/RouteData[<=1] | lanelet 格式的路由 |
