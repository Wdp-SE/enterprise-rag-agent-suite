# Category crosswalk

## 分类：人行横道

人行横道有两种类型的要求,它们都可以适用于单个人行横道.

- [vm-05-01](./#vm-05-01-crosswalks-across-the-road) ： 马路对面的人行横道
- [vm-05-02](./#vm-05-02-crosswalks-with-pedestrian-signals) ： 有行人信号的人行横道

在交叉路口出现人行横道的情况下,它们还必须满足交叉路口的要求.

---

### vm-05-01 横跨马路的人行横道

#### 在 toc 中省略的要求细节

创建必要条件：

1. 为人行横道创建一个 Lanelet ( *subtype：crosswalk* ).
2. 如果人行横道前有停止线,则创建一个 Linestring ( *type：stop_line* ).以相同的方式为对面的车道创建停止线.
3. 创建一个多边形 ( *type：crosswalk_polygon* ) 以覆盖人行横道.
4. 道路的 Lanelet 是指监管要素 ( *subtype：crosswalk* ),监管要素是指创建的 Lanelet、Linestring 和 Polygon.

##### 补充信息

- 将监管要素与与人行横道相交的道路车道连接起来.
- 与监管要素相关的停止线不一定存在于与监管要素相关的车道上.

##### Autoware 的行为： toc  中省略

当行人或骑自行车的人在人行横道上时,Autoware 将在停止线前停下来并等待他们通过.一旦他们清理了该区域,Autoware 将开始前进.

### vm-05-02 带行人信号的人行横道

#### 在 toc 中省略的要求细节

创建必要条件：

- 创建一个 Lanelet ( *subtype：crosswalk* , *participant：pedestrian* ).
- 创建交通灯线串.如果存在多个红绿灯,请创建多个 Linestring.
- 线串
- *type：traffic_light*
- *subtype：red_green*
- *height* ：值
- 确保人行横道的 Lanelet 引用监管元素 ( *subtype：traffic_light* ).此外,请确保 Regulatory Element 引用 Linestring ( *type：traffic_light* ).

有关交通信号灯对象的更多信息,请参阅 [vm-04-02](../category_traffic_light/#vm-04-02-traffic-light-position-and-size).

### vm-05-03 人行横道上的安全减速

#### 在 toc 中省略的要求细节

为确保在穿越人行横道时始终减速至安全速度,请将以下标签添加到人行横道的 Lanelet (*subtype：crosswalk*)：

- *safety_slow_down_speed* [m/s]：穿越时的最大速度.
- *safety_slow_down_distance* [m]： 从车辆前保险杠到人行横道测量的最大速度区域的起点.

### vm-05-04 栅栏

#### 在 toc 中省略的要求细节

Autoware 会检测穿过人行横道的行人和自行车,以及可能穿过人行横道的行人和自行车.但是,人行横道附近的区域(例如带围栏的幼儿园、游乐场或公园)可能会因为预测到来自这些区域的人和自行车的路径而影响人行横道检测.

使用 Linestring (*type：fence*) 包围未连接到人行横道的区域,它不需要链接到任何东西.

但是,如果道路和人行道之间有护栏、墙壁或栅栏,后面有另一个栅栏,则可以省略第二个栅栏.然而,人行横道周围的区域不受此遗漏的约束,必须不排除地创建.
