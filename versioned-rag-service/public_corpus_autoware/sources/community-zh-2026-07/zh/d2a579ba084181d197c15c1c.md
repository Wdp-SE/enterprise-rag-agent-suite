# 许可证

Autoware 根据 Apache License 2.0 获得许可. 因此,所有贡献都将按照 Apache 许可证 2.0 的第 5 条获得许可：

```
5. 提交贡献.除非您另有明确说明,
   任何有意提交以包含在作品中的贡献
   您向许可方发送的协议应遵守
   本许可,无任何其他条款或条件.
   尽管有上述规定,此处的任何内容均不得取代或修改
   您可能已签署的任何单独许可协议的条款
   就此类贡献与许可方共享.
```

以下是要添加到新文件顶部的 copyright 标头示例：

```
Copyright [first year of contribution] The Autoware Contributors
SPDX-License-Identifier: Apache-2.0
```

我们不在这里写下每个贡献者的版权符号. 相反,我们将它们放在 `NOTICE` 文件中,如下所示.

```
This product includes code developed by [company name].
Copyright [first year of contribution] [company name]
```

如果您的法律部门对版权表示法有特殊要求,请告诉我们.

目前,[这里](https://gitlab.com/autowarefoundation/autoware.auto/AutowareAuto/-/blob/87c5e5880a18068116dd886ad56e1bfc29e694c4/CONTRIBUTING.md) 解释的旧格式也是可以接受的. 如果原作者同意,这些旧格式可以被这种新格式替换. 请注意,除非他们同意新格式,否则我们不会将他们的版权写入 `NOTICE` 文件.
