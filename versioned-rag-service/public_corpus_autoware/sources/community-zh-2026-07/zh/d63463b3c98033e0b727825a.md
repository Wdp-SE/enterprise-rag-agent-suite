# 雷达点云数据

## 概述

### 管道

此图描述了雷达点云的预处理管道.

（图片说明：雷达点云感应；未对图片像素执行 OCR）

### 接口

-输入 - 来自设备的雷达数据 - 自我车辆运动的扭曲信息 -输出 - 动态雷达点云 (`ros-perception/radar_msgs/msg/RadarScan.msg`) - 噪声过滤雷达点云 (`sensor_msgs/msg/Pointcloud2.msg`)

### 备注

- 在传感层,雷达预处理包通过带有传感器坐标的 `ros-perception/radar_msgs/msg/RadarScan.msg` 消息类型过滤噪声.
- 对于 LiDAR 包对雷达点云数据的使用,我们想提出一个转换器,用于从 `ros-perception/radar_msgs/msg/RadarScan.msg` 创建 `sensor_msgs/msg/Pointcloud2.msg` .

## 参考实现

### 雷达数据消息

Autoware 使用雷达对象数据类型为 [radar_msgs/msg/RadarScan.msg](https://github.com/ros-perception/radar_msgs/blob/ros2/msg/RadarScan.msg). 具体请参见 [雷达数据消息](../reference-implementations/data-message/).

### 雷达设备驱动程序

自动软件支持雷达驱动程序的 `ros-perception/radar_msgs/msg/RadarScan.msg` 和 `autoware_auto_perception_msgs/msg/TrackedObjects.msg` .

具体请参见 [雷达设备驱动程序](../reference-implementations/device-driver/).

### 基本噪声滤波器

- [radar_threshold_filter](https://github.com/autowarefoundation/autoware_universe/tree/main/sensing/radar_threshold_filter)

此软件包可消除低振幅、边缘角度、阈值太接近点云的点云噪声. 噪声取决于雷达设备和安装位置.

### 过滤到静态/动态点云

- [radar_static_pointcloud_filter](https://github.com/autowarefoundation/autoware_universe/tree/main/sensing/radar_static_pointcloud_filter)

该软件包使用多普勒速度和自我运动提取静态/动态雷达点云. 静态雷达点云可用于 NDT 扫描匹配等定位,动态雷达点云可用于动态目标检测.

### 从 RadarScan 到 Pointcloud2 的消息转换器

- [radar_scan_to_pointcloud2](https://github.com/autowarefoundation/autoware_universe/tree/main/sensing/radar_scan_to_pointcloud2)

为了在现有的 LiDAR 包中方便地使用雷达点云,我们建议使用 `radar_scan_to_pointcloud2_convertor` 包将 `ros-perception/radar_msgs/msg/RadarScan.msg` 转换为 `sensor_msgs/msg/Pointcloud2.msg` .

|  | LiDAR package | Radar package |
| --- | --- | --- |
| message | sensor_msgs/msg/Pointcloud2.msg | ros-perception/radar_msgs/msg/RadarScan.msg |
| coordinate | (x, y, z) | (r, θ, φ) |
| value | intensity | amplitude, doppler velocity |

对于考虑过的使用案例,

- 使用 [pointcloud_preprocessor](https://github.com/autowarefoundation/autoware_universe/tree/main/sensing/pointcloud_preprocessor) 进行雷达扫描.
- 将 [地面分割](https://github.com/autowarefoundation/autoware_universe/tree/main/perception/autoware_ground_segmentation) 等障碍物分割应用于无 LiDAR(摄像头 + 雷达)系统的雷达点.
