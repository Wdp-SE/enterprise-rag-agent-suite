# /api/remote/operator/status

## 状态

- 最后版本: not released
- 方法: realtime stream
- 数据类型: [autoware_adapi_v1_msgs/msg/ManualOperatorStatus](../../../../../types/autoware_adapi_v1_msgs/msg/ManualOperatorStatus/)

## 描述

应用程序需要确定作员是否能够通过此 API 驾驶和发送该信息. 有关详细信息,请参阅 [手动控制](../../../../../features/manual-control/).

## 消息

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| stamp | builtin_interfaces/msg/Time | 发送此消息时的时间戳. |
| ready | bool | 作员是否能够继续驾驶. |
