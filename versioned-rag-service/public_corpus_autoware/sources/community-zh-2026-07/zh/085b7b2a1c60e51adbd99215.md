# /api/operation_mode/enable_autoware_control

## 状态

- 最后版本: v1.0.0
- 方法: function call
- 数据类型: [autoware_adapi_v1_msgs/srv/ChangeOperationMode](../../../../types/autoware_adapi_v1_msgs/srv/ChangeOperationMode/)

## 描述

通过 Autoware 启用车辆控制. 有关详细信息,请参阅 [操作模式](../../../../features/operation_mode/) 中. 如果车辆不支持软件更改模式,则此 API 失败.

## 请求

None

## 响应

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| status | autoware_adapi_v1_msgs/msg/ResponseStatus | 响应状态 |
