# /api/routing/change_route

## 状态

- 最后版本: v1.5.0
- 方法: function call
- 数据类型: [autoware_adapi_v1_msgs/srv/SetRoute](../../../../types/autoware_adapi_v1_msgs/srv/SetRoute/)

## 描述

与 [/api/routing/set_route](../set_route/) 相同,但在驾驶时更改路线. 仅当路由状态为 SET 时,此 API 才接受路由. 在任何其他状态下,请先设置路由或等待路由更改完成.

## 请求

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| header | std_msgs/msg/Header | 用于姿势转换的标头 |
| goal | geometry_msgs/msg/Pose | 目标姿势 |
| segments | autoware_adapi_v1_msgs/msg/RouteSegment[] | Lanelet 格式的 Waypoint Segments |

## 响应

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| status | autoware_adapi_v1_msgs/msg/ResponseStatus | 响应状态 |
