# 定位(Localization)

## 相关 API

- [/api/localization/initialization_state](../../list/api/localization/initialization_state/)

## 描述

此 API 管理定位(Localization)的初始化.Autoware 需要全局姿势作为定位(Localization)的初始猜测.
