## 描述

如果车辆为车门提供软件界面,则此功能可用. 它可用于为乘客创建用户界面或控制公交车站的顺序.

## 布局

车辆中的每个门都分配有一个数组索引.此分配取决于车辆. 布局 API 会返回此信息. description 字段是要在用户界面中显示的字符串,等等. 这是一个任意字符串,不建议用于应用程序中的处理. 使用 roles 字段了解用于上下车的门. 以下是布局 API 返回的信息示例.

| 指数 | 描述 | 角色 |
| --- | --- | --- |
| 0 | 正面 右 | - |
| 1 | 左前 | GET_ON |
| 2 | 右后 | GET_OFF |
| 3 | 左后 | GET_ON、GET_OFF |

## 状态

状态 API 提供了一组门状态.此数组顺序与布局 API 一致.

## 控制

使用命令 API 控制门. 与 status 和 layout API 不同,数组索引不对应于 doors. 该命令具有一个字段,用于指定目标门索引.
