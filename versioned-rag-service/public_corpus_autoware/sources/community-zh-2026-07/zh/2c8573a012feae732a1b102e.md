# /api/vehicle/status

## 状态

- 最后版本: v1.4.0
- 方法: realtime stream
- 数据类型: [autoware_adapi_v1_msgs/msg/VehicleStatus](../../../../types/autoware_adapi_v1_msgs/msg/VehicleStatus/)

## 描述

发布车辆状态信息.

## 消息

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| gear | autoware_adapi_v1_msgs/msg/Gear | 齿轮状态. |
| turn_indicators | autoware_adapi_v1_msgs/msg/TurnIndicators | 转向指示灯状态,仅启用左侧或右侧. |
| hazard_lights | autoware_adapi_v1_msgs/msg/HazardLights | 危险信号灯状态. |
| steering_tire_angle | float64 | 车辆当前轮胎角度(以弧度为单位). |
