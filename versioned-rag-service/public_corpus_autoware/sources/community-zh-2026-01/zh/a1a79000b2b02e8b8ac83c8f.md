# /api/local/command/pedals

## Status

- Latest Version: not released
- Method: realtime stream
- Data Type: [autoware_adapi_v1_msgs/msg/PedalsCommand](../../../../../types/autoware_adapi_v1_msgs/msg/PedalsCommand/)

## Description

发送在本地作模式下使用的踏板命令.踏板值是最大踏板踩下为 1.0 的比率. 如需使用此 API,请按照 [手动控制](../../../../../features/manual-control/).

## Message

| Name | Type | Description |
| --- | --- | --- |
| stamp | builtin_interfaces/msg/Time | 发送此消息时的时间戳. |
| accelerator | float32 | 目标油门踏板比率. |
| brake | float32 | 目标制动踏板比率. |
