# 运动

## 相关 API

- [/api/motion/state](../../list/api/motion/state/)
- [/api/motion/accept_start](../../list/api/motion/accept_start/)

## 描述

此 API 管理车辆的当前行为. 应用程序可以将车辆行为通知周围的人,并为作员和乘客可视化.

## 状态

运动状态管理车辆的停止和启动. 车辆停止后,状态将为 STOPPED. 在此之后,当车辆尝试启动 (仍处于停止状态) 时,状态将为 STARTING. 在此状态下,调用 start API 会将状态更改为 MOVING 并且车辆启动. 此机制可以在车辆启动之前添加公告等处理. 根据配置,状态可能会直接从 STOPPED 转换为 MOVING.

| 州 | 描述 |

| 启动 | 车辆已停止,但正在尝试启动. |
| 搬家 | 车辆正在移动. |
| 制动 (T.B.D.) | 车辆正在急剧减速. |
