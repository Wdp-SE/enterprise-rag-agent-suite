# /api/system/diagnostics/status

## Status

- Latest Version: v1.3.0
- Method: realtime stream
- Data Type: [autoware_adapi_v1_msgs/msg/DiagGraphStatus](../../../../../types/autoware_adapi_v1_msgs/msg/DiagGraphStatus/)

## Description

这是诊断的动态部分. 如果使用新 ID 发布静态数据,请忽略使用旧 ID 的动态数据. 请参阅 [诊断](../../../../../features/diagnostics/) 了解详细信息.

| Name | Type | Description |
