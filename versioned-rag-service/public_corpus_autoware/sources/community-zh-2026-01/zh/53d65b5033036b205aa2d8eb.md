# /api/routing/change_route_points

## Status

- Latest Version: v1.5.0
- Method: function call
- Data Type: [autoware_adapi_v1_msgs/srv/SetRoutePoints](../../../../types/autoware_adapi_v1_msgs/srv/SetRoutePoints/)

## Description

与 [/api/routing/set_route_points](../set_route_points/) 相同,但在驾驶时更改路线. 仅当路由状态为 SET 时,此 API 才接受路由. 在任何其他状态下,请先设置路由或等待路由更改完成.

## Request

| Name | Type | Description |
| --- | --- | --- |
| header | std_msgs/msg/Header | 用于姿势转换的标头 |
| goal | geometry_msgs/msg/Pose | 目标姿势 |
| waypoints | geometry_msgs/msg/Pose[] | 航点姿势 |

## Response

| Name | Type | Description |
| --- | --- | --- |
| status | autoware_adapi_v1_msgs/msg/ResponseStatus | 响应状态 |
