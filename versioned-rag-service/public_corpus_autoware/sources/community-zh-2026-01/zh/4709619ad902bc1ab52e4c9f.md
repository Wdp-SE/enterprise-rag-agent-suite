# 创建车辆和传感器模型

## 概述

### 传感器模型

- **目的:** 传感器模型包括 自动驾驶汽车中使用的传感器. 这包括各种传感器,如 LiDAR、摄像头、 雷达、 IMU (惯性测量单元)、GPS 单元等

- **重要性:** 准确的传感器建模对于感知任务至关重要. 精确的校准值通过处理传感器数据来帮助了解环境, 例如检测物体、估计距离、 以及创建周围环境的 3D 表示.

- **用法:** 传感器模型在 Autoware 中用于启动传感器, 配置他们的管道,并描述校准值.

- 传感器型号(传感器套件)由以下三个封装组成：
- `common_sensor_launch`
- `<YOUR_VEHICLE_NAME>_sensor_kit_description`
- `<YOUR_VEHICLE_NAME>_sensor_kit_launch`

请参考 [创建传感器模型](creating-sensor-model/) 页面 用于创建您的个性化传感器模型.

作为参考,以下是 Autoware 中 [sample_sensor_kit_launch](https://github.com/autowarefoundation/sample_sensor_kit_launch) 包的文件夹结构：

```
sample_sensor_kit_launch/
├─ common_sensor_launch/
├─ sample_sensor_kit_description/
└─ sample_sensor_kit_launch/
```

### 车辆型号

- **目的:** 车辆模型包括单个车辆规格,包括尺寸、 车辆的 3D 模型(.fbx 或 .dae 格式)等.

- **重要性:** 精确的车辆模型对于运动规划和控制至关重要.

- **用法:** 车辆模型在 Autoware 中用于为 Autoware 提供车辆信息. 包括车辆的 3D 模型.

- 该车型包括以下两个包装：
- `<YOUR_VEHICLE_NAME>_vehicle_description`
- `<YOUR_VEHICLE_NAME>_vehicle_launch`

请查阅 [创建车辆模型](creating-vehicle-model/) 页面创建您的个人车辆模型.

作为参考,以下是 Autoware 中 [sample_vehicle_launch](https://github.com/autowarefoundation/sample_vehicle_launch) 包的文件夹结构：

```
sample_vehicle_launch/
├─ sample_vehicle_description/
└─ sample_vehicle_launch/
```
