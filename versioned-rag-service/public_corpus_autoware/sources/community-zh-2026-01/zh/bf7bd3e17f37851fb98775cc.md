# 自动软件 AD API

## 概述

Autoware AD API 是从自动驾驶系统外部作车辆的接口. [有关 Autoware 的整体界面设计,请参阅此处.(../index.md)

## 用户故事

用户情景是 AD API 假定的服务方案.AD API 是根据这些方案设计的. 每个场景都是通过后面描述的使用案例组合实现的. 如果存在无法覆盖的场景,请讨论添加用户故事.

- [公交服务](stories/bus-service/)
- [出租车服务](stories/taxi-service/)

用例是从用户情景派生并采用通用设计的部分方案. 服务提供商可以组合这些用例来定义用户故事,并检查 AD API 是否可以应用于他们自己的场景.
