# /api/routing/set_route

## Status

- Latest Version: v1.0.0
- Method: function call
- Data Type: [autoware_adapi_v1_msgs/srv/SetRoute](../../../../types/autoware_adapi_v1_msgs/srv/SetRoute/)

## Description

使用 lanelet 格式的 waypoint Segment 设置路线.如果未指定 start pose,则将使用当前姿势. 此 API 仅在路由状态为 UNSET 时接受路由.在任何其他状态下,请先清除路由.

## Request

| Name | Type | Description |
| --- | --- | --- |
| header | std_msgs/msg/Header | 用于姿势转换的标头 |
| goal | geometry_msgs/msg/Pose | 目标姿势 |
| segments | autoware_adapi_v1_msgs/msg/RouteSegment[] | Lanelet 格式的 Waypoint Segments |

## Response

| Name | Type | Description |
| --- | --- | --- |
| status | autoware_adapi_v1_msgs/msg/ResponseStatus | 响应状态 |
