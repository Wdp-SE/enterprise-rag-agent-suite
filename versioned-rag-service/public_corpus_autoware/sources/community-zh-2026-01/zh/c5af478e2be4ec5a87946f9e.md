# /api/operation_mode/disable_autoware_control

## Status

- Latest Version: v1.0.0
- Method: function call
- Data Type: [autoware_adapi_v1_msgs/srv/ChangeOperationMode](../../../../types/autoware_adapi_v1_msgs/srv/ChangeOperationMode/)

## Description

禁用 Autoware 的车辆控制. 有关详细信息,请参阅 [作模式](../../../../features/operation_mode/) 中. 如果车辆不支持软件更改模式,则此 API 失败.

## Request

None
