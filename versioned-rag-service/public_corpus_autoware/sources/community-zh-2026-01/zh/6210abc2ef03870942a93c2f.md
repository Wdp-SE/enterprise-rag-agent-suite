# SC-A-LOAM

## 什么是 SC-A-LOAM？

- 集成了 A-LOAM 和 ScanContext 的实时 LiDAR SLAM 软件包.

## 存储库信息

### 原始仓库 link

[https://github.com/gisbi-kim/SC-A-LOAM](https://github.com/gisbi-kim/SC-A-LOAM)

### Required Sensors

- LIDAR [VLP-16, HDL-32, HDL-64, Ouster OS1-64]

### Prerequisites (dependencies)

- ROS
- GTSAM version 4.x.

- 如果未安装 GTSAM,请按照以下步骤作.  cspell: ignore DGTSAM `wget-O~/Downloads/gtsam.ziphttps://github.com/borglab/gtsam/archive/4.0.2.zip cd~/Downloads/&&unzipgtsam.zip-d~/Downloads/ cd~/Downloads/gtsam-4.0.2/ mkdirbuild&&cdbuild cmake-DGTSAM_BUILD_WITH_MARCH_NATIVE=OFF.. sudomakeinstall-j8`

### ROS 兼容性

- ROS 1

## 构建并运行

### 1) 构建

- 首先,安装上述依赖项并按照以下几行作.  cspell: ignore scaloam `mkdir-p~/catkin_scaloam_ws/src cd~/catkin_scaloam_ws/src gitclonehttps://github.com/gisbi-kim/SC-A-LOAM.git cd../ catkin_make source~/catkin_scaloam_ws/devel/setup.bash`

### 2) 设置参数

- 下载存储库后,更改启动文件的主题和传感器设置.

### 扫描上下文参数

- 如果遇到重影错误或循环未关闭,请更改扫描上下文参数.
- 使用标记区域中的参数调整扫描上下文设置.

（原文含图片，未对图片像素执行 OCR）

### 3) 运行

```
roslaunch aloam_velodyne aloam_mulran.launch
```

## 4) 另存为 PCD 文件

```
rosrun pcl_ros pointcloud_to_pcd input:=/aft_pgo_map
```
