# 公交服务的用户故事

## 概述

此用户情景是一项出租车服务,用于接载乘客并将他们送到目的地.

## 场景

| 步骤 | 运营 | 使用案例 |
| --- | --- | --- |
| 1 | 启动自动驾驶系统. | 启动和终止 |
| 2 | 将车辆从车库开到等待位置. | 更改作模式 |
| 3 | 启用自主控制. | 更改作模式 |
| 4 | 将车辆开到要取货的位置. | 行驶至指定位置 |
| 5 | 上车. | 上下车 |
| 6 | 将车辆驾驶至目的地. | 行驶至指定位置 |
| 7 | 下车. | 上下车 |
| 8 | 将车辆开到等待位置. | 行驶至指定位置 |
| 9 | 如果有其他请求,请返回步骤 4. |  |
| 10 | 将车辆从等候位置开到车库. | 更改作模式 |
| 11 | 关闭自动驾驶系统. | 启动和终止 |
