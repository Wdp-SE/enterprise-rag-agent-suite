# 外部用户试用指南

## 当前状态

本指南供公网部署后的 3～5 名真实用户试用。截至当前尚未开展真实外部用户试用，因此没有用户数、完成率、用时或满意度结论。

## 试用任务

1. 打开 Public Demo。
2. 选择 Case A 或 Case B。
3. 查看当前有效版本与历史版本。
4. 查看需求变化。
5. 查看已确认关系与疑似影响。
6. 展开 Evidence，核对文档、版本、章节和引用。
7. 查看 Patch Before / After，并完成审核。
8. 发布 Candidate Version。
9. 查看校验、激活结果和新版本检索。

主持人不得提前告诉正确答案或代替点击，不收集姓名、邮箱、单位等敏感信息。免费后端冷启动时，只提示等待并点击“重新连接”。
