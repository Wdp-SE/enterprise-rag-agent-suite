# 首次访问与三分钟演示流程

1. 打开首页，先读标题、副标题和 Public Demo 提示。这里使用合成研发资料，展示真实的版本可信检索与变更审查流程。
2. 看“当前项目状态”：项目和需求版本随所选案例变化；文档与版本数量来自当前目录；系统状态须为 Ready 才适合进行完整演示。
3. 在“开始一次变更审查”选择案例。Case A 是并发容量由 500 调整为 1000；Case B 是审计日志保存周期由 7 天调整为 30 天。
4. 点击“开始分析”或“开始 Demo”，进入“变更分析”。两个按钮只导航到同一个现有流程，不自动批准或发布。点击“运行变更分析”，查看识别出的需求差异、已确认及疑似影响、可追溯引用依据。
5. 进入“修改审核”，逐条对照“修改前 / 建议修改 / 引用依据”，检查依据所属文档、版本、章节和页码。填写审核人和意见，再使用现有的批准、编辑或驳回操作；未审核的修改不会被直接发布。
6. 进入“版本发布”，先应用已批准的修改，再执行候选版本校验和安全发布。界面展示原有质量门禁结果、候选版本状态及校验项。
7. 如需延伸讲解，可打开“知识检索”演示版本范围下的可信问答与引用，或打开“执行轨迹”“评测结果”说明可追踪性与评测。文档模板起草位于“扩展工具”，不属于这条核心三分钟路径。

遇到服务休眠或暂时断连时，等系统恢复 Ready 后重试当前操作。界面不会用静态样例代替后端运行结果。
