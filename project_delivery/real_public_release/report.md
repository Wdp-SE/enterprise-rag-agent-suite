## 真实查询集与策略

46 条经固定官方来源逐条验证的查询：可回答 43 条、故意无答案 3 条；涵盖中文、英文、中英混合、精确术语、版本、跨文档及易误命中查询。所有策略使用同一语料、Query、版本过滤和 Top-5。Dense 是 512 维字符 n-gram 哈希余弦基线，不是神经语义 Embedding；Hybrid 使用 RRF(k=60)。延迟是本地进程内检索，不含 HTTP / LLM。

## 产品与安全边界

公网默认入口只显示真实官方资料的研发知识 RAG 与变更审查 Agent，合成 Case A/B 留作旧版测试夹具。Agent 调用实际 RAG HTTP 检索及既有 Diff / Impact 服务；只有 PR 正文明确引用 DSIP 的关系标记“已确认”，其余检索相关资料均标记“建议 / 可能受影响”。假设变更和审核结果只保留在 Streamlit 当前会话，不创建公开候选版本，不写 Apache 上游或公共语料。资料一致性提醒仅针对可核验版本文字差异与明确参数值差异，不估计伪精确概率。

## UI/UX 收口（本轮）

- 集中样式以黑、白、深灰和克制蓝灰为主；通过明确边框、版本状态栏、分组侧栏、引用区与真实步骤条建立工程审查工作台层级。深色检索模块及活动导航经过实际浏览器对比度复核。
- 侧栏增加“知识服务”“变更审查”“系统说明”三组真实页面；版本历史与资料来源直接读取现有官方目录，检索评测直接读取已保存的真实 Benchmark，不新增 RAG/Agent API 或核心业务判断。
- RAG 页将版本/语言范围、问题、回答与引用依据组织为双栏阅读路径；Top 3 依据默认呈现，其余折叠。资料一致性提醒显示可核验的来源、版本及当前回答的一条已引用来源，不臆断该来源是模型的“主要依据”；明确文字差异不等于事实矛盾。
- Agent 页按输入变更、影响候选、引用依据、修改建议、人工审核组织；已确认关系与仅建议核对的候选分别显示。选择新段落会重置旧草案和审核状态；同名 DSIP Issue / PR 依来源类型区分；步骤状态与真实审查进度一致。会话内草案和公共资料边界保持不变。
- 新增 UI 验收测试采用测试先行：旧界面缺失新导航/提醒展示的测试先失败，落地后通过。浏览器 Smoke 新增真实官方 Parameter Priority 双版本差异场景，并在实际选中的 DSIP 段落上追加局部假设。截图已更新。

## 仍有限制

真实语料是官方资料的有限子集，无法代表 DolphinScheduler 全站准确率；跨文档组只有四题且召回较弱。无答案问题的检索候选仍会出现，不能自动证明无答案；未配置模型密钥时只提供证据检索。当前截图和测试均为本地，公网需后续 code review、提交和部署后再验收。
