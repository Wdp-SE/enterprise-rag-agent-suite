状态：**DEV 比较后选择 BM25；V3 HOLDOUT 已按锁定候选运行一次。HOLDOUT 结果用于验证，不再据此修改题目、语料或检索策略。**

- 固定的 DolphinScheduler 官方语料：3.4.2 / 3.4.3，中文与英文共 **132 份来源、1322 个片段**。语料 manifest SHA-256：`453d9de964b1c116cfa1ab9e4ed4446135da2567dac12ef8778a8b1d0350e996`。

- V2 的题目、HOLDOUT 和实验结果未作为 V3 调参材料。此 V3 的题目及标注存在仓库中，因此它是**一次性锁定的离线评测**，不是对开发者完全不可见的独立盲测。

| 指标 | DEV BM25 |

| 题数 / 可回答 / 无答案 | 36 / 32 / 4 |
| 来源 Hit@5：至少命中一份必需来源 | 0.9688 |
| 来源 Recall@5：每题必需来源覆盖比例的平均 | 0.9531 |
| 来源 Recall@5：全部必需来源的总体比例 | 0.9250 |

所有单来源类别的来源完整命中率均为 4/4。跨文档类别为 2/4，来源 Recall@5 为 0.625，返回片段证据锚点召回为 0.50；跨版本类别为 4/4。失败题体现了真实需要改进的环节：

- `c02` 同时需要 3.4.2 的任务组队列优先级和工作流流程优先级；Top-5 返回工作流定义，却漏掉任务组来源。

无答案题只有 Top-1 检索分数诊断：4 条的中位数约 15.10、P95 约 19.89。出现高检索分数并不表示资料能回答问题，不能据此报告拒答率或幻觉率。

## DEV 候选诊断

在相同冻结输入和相同代码指纹（`public_knowledge.py` SHA-256：`f043f5e6f7ed9a57ebc0423d9a61352cabdd48fba3b9ccb5e83e3500451158c5`）上，额外测了三种显式的来源多样化排序。它们都保留 BM25 作为基础打分，只改变最终 Top-5 片段的来源分布。

| DEV 策略 | 全部来源完整命中 | 多来源完整命中 | 返回片段原文锚点 | warm P95 |
| --- | ---: | ---: | ---: | ---: |
| BM25 | 30/32 | 6/8 | 44/48 | 7.52 ms |
| BM25 来源多样化 | 31/32 | 7/8 | 41/48 | 8.65 ms |
| 保留 Top-2 后来源多样化 | 31/32 | 7/8 | 42/48 | 7.59 ms |
| 保留 Top-3 后来源多样化 | 31/32 | 7/8 | 43/48 | 6.97 ms |

三种候选都多找齐一题的必需来源，但也把若干含有关键原文的片段挤出了 Top-5。Top-3 方案的损失最小，仍比 BM25 少一个证据锚点。根据 DEV 的来源与片段证据综合表现，最终锁定 **BM25** 作为 HOLDOUT 唯一受测策略。36 条题的一次本机耗时样本过小，不能据几毫秒差异判断公网性能优劣。

## 解释与后续

来源命中和片段锚点分别计数；同一来源的多个片段不会虚增来源召回。证据锚点命中也只证明固定文字被找到了，**不能证明答案逐句受证据支持**。本机 warm 耗时不包括读取索引、HTTP、模型生成或公网冷启动。

当前索引只收录固定 Markdown 文本及其文本片段，**图片二进制和图片内文字没有进入索引或 OCR**。Markdown 图片引用的文件名、替代文字可能被当作文本检索到，但不能据此声称识别了图中的内容；图上独有的信息仍是覆盖缺口。

单来源题含明确领域术语，DEV 分数高，不能据此外推到真实用户开放提问。V3 的一次性 HOLDOUT 已揭示了跨文档、跨版本与精确操作依据的缺口；修复这些问题应在**新的评测版本和新的独立切分**上验证，不回头调整 V3 或再次打开其 HOLDOUT。无答案检索分数、检索锚点召回与生成答案的幻觉率是不同指标，后两者需要单独的人工事实核验。
