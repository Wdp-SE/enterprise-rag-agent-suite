# Reliability and data boundaries

`DocumentWorkflowConfig` centralizes the RAG URL, frozen `/retrieve` endpoint, RAG timeout/retry/top_k, NoProgress threshold, workflow/section steps, tool-call and token budgets, workflow timeout, output/checkpoint/trace roots, full Evidence export preference, profile, and required human review. It validates URL, positive timeouts and limits, retry, top_k, paths, profile, and review before work starts. Environment variables provide overrides; no API key or token is embedded in new code or demo JSON. The local `config/config.toml` and `.env` are ignored by `.gitignore`, as are runtime recovery state, Evidence store, Evidence JSON, and traces. This copy lacks Git metadata, so tracked-file status cannot be independently checked here.

The HTTP adapter owns retry: connection and timeout failures or 5xx may retry at most the configured limit; malformed JSON, schema/metadata invalidity, and non-5xx responses do not retry. Workflow does not wrap the adapter in another retry loop. A failed section saves a PARTIAL state and missing content; Browser/Search and direct FAISS remain denied. BudgetLedger, NoProgressDetector, TaskPolicy, and structured Trace are the existing reliability components reused by this workflow.

Trace records workflow/task/section identity, query SHA256, Evidence IDs, counts, status, duration, and error type. It does not record full retrieved body or secret headers. The default Evidence JSON contains metadata and hashes without full body; enabling `DOCUMENT_WORKFLOW_PERSIST_FULL_EVIDENCE_TEXT=true` exports body only to the Evidence artifact. Recovery checkpoints always contain body for resume and must stay in a restricted local directory. Sanitization and minimized logs reduce accidental disclosure, but they are not an enterprise DLP or access-control system.

The OutputIntegrityValidator verifies required sections, draft completeness, missing reasons, citations and cache membership, the template ID/hash, distinct output path, and human review before DOCX finalization. Evidence membership prevents fabricated IDs; it does not prove semantic entailment or absolute factual accuracy. Human review remains the release boundary.
